# Third-party protocol descriptions

These unmodified JSON interface descriptions are distributed by **pump-fun** in the official npm
packages `@pump-fun/pump-sdk` 4.0.0 and `@pump-fun/pump-swap-sdk` 2.1.0. Both packages declare the
MIT license in their published package metadata. Source paths, versions and byte hashes are
retained in `sources.json`. The observed documentation Git commit is informational; these files
were extracted from the pinned npm packages, not claimed to have been fetched from that commit.

Only protocol descriptions are retained. The runtime SDKs, transaction builders, wallet code
and their transitive dependency trees are not part of CrawlSpider's installed dependencies.
